    FAQ and troubleshooting¶

    Known limits¶

    • Only the Arcadyan AW1000, and only with the expanded flash layout. See MTD layout.
    • The first install from the stock firmware needs a serial console.
    • QModem is not free for commercial use. Its licence adds a non-commercial clause. See Licence and notices.
    • AWvoice is not for emergency calls. See the safety notes on the AWvoice page.
    • Images are unsigned unless the project's image-signing key is configured for the release.
    • The cw-opt package feed is not active yet.
    • The modem's own firmware is separate and is not provided by this project.

    Questions¶

    Does OpenWrt run on the Arcadyan AW1000?

    Yes. CleanWRT is OpenWrt 25.12.5 built for the AW1000 (qualcommax/ipq807x), with the 5G modem, Wi-Fi, the front-panel LEDs and the RJ11 phone port working. It needs the expanded flash layout, see the MTD layout page.

    Can I use a normal phone on the AW1000's RJ11 port?

    Yes, with AWvoice, which is part of CleanWRT: an ordinary analogue phone makes and takes calls over the SIM.

    Does the AW1000 do VoLTE voice calls on OpenWrt?

    Yes, with AWvoice. The 5G modem carries the call over VoLTE, so you need a SIM and an operator that provide VoLTE.

    Why does the browser say the connection is not secure?

    LuCI uses a self-signed certificate created on your router at first boot. The connection is encrypted, but no public authority signed the certificate. See Security.

    I cannot log in after flashing.

    The first login is over Ethernet with no password, at http://192.168.1.1. Connect a computer to a LAN port and set its address to 192.168.1.x if it does not get one. If it still fails, use failsafe mode.

    Can I flash it on my router if it is not an AW1000?

    No. Never flash an image built for another device. It can brick the router.

    sysupgrade says the image is not valid.

    Check the file name (arcadyan_aw1000), re-download the image and check its checksum. If you flash a community build that has no metadata, you would need -F; do not force an image you did not verify.

    The 5G modem does not register.

    Open Modem → QModem and Modem → 3gInfo-lite and check the SIM, the APN and the signal. See The 5G modem. A modem firmware upgrade is only a last resort.

    The 5G and signal LEDs went dark.

    The LED daemon cannot read the modem. Check that nothing holds the AT port open, and read logread -e cw-led. See Front-panel LEDs.

    Wi-Fi works but 'Internet' says unreachable.

    Open the connectivity check settings in System → LED Management. The LED only mirrors the probe. Test the real connection from a computer too.

    Cloudflared shows a red error.

    That is expected until you configure the tunnel token. See Remote access.

    I ran apk upgrade and the overview cards look different.

    The LuCI packages are pinned for a reason (see Updating and pinning). Flash the release again to get back to its state. A factory reset does not restore replaced packages.

    Downloads are filling the router's flash.

    Downloads default to the first USB drive. Plug a drive in before you start a download.

    Can I use it commercially?

    The project is free of charge. The bundled QModem component prohibits commercial use. Check its licence before you deploy this firmware in a business, an ISP or a paid service.

    How do I go back to the stock firmware?

    Restoring the stock firmware needs the stock image and a serial console. Keep a backup of the stock firmware before you flash.

    What is the default IP address and login of CleanWRT on the AW1000?

    The router answers at http://192.168.1.1 over Ethernet, with no root password at first. LuCI asks you to set one. Wi-Fi starts as CleanWRT-5G and CleanWRT-2.4G with the default key CleanWRT#40, so change it on the first login.

    Do I need a serial cable to install OpenWrt on the AW1000?

    For the first install from the stock firmware, yes: a 3.3 V USB-UART adapter and a TFTP server. If the router already runs OpenWrt, you can update with sysupgrade or from LuCI with no cable. See Installation.

    Where do I download the AW1000 firmware, and how do I verify it?

    On the GitHub Releases page of the project. Check the file with sha256sum -c sha256sums.cw --ignore-missing before you flash, and make sure the file name contains arcadyan_aw1000. See Releases.

    How do I recover an AW1000 that will not boot?

    If the router boots but you cannot reach it, use failsafe mode over Ethernet. If it is stuck at the bootloader, use the serial console to boot an initramfs image over TFTP and flash again. See Recovery.

    Still stuck?¶

    1. Collect a diagnostic capture: cw-diag full (SIM identifiers, public IPs and Wi-Fi keys are redacted).
    2. Read the Recovery page.
    3. Open an issue on GitHub with the version, what you did, and the relevant log lines. Do not paste passwords or keys.
